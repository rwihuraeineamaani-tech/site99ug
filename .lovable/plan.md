## 3. Receipt download
Each payment recorded against an invoice gets a "download receipt" button. The receipt uses the same layout, with these changes:
- The receipt number, date received and linked invoice number
- "Received From" instead of "Billed To"
- "Total Paid" instead of "Totals to be Paid"
- The payment method and transaction ID

The same buttons also show in the client portal, so clients can download their own copies.

## Technical notes
- Before deleting, save a CSV of each table to /mnt/documents/finance-backup-2026-09/. Then delete with run_sql, working from child tables up to parent tables: invoice_lines, payment_run_lines, loan_repayments, cashbook_entries, shoot_spend, invoices, cash_requests, payment_runs, loans, client_funds, finance_audit. Also reset invoice_counters and txn_counters, and set wallets.balance to 0.
- Make sure clearing invoices doesn't change client status by mistake: after the reset, re-run recompute_all_lifecycles and check the status of the 5 clients with contracts.
- Build the PDFs in the browser with jspdf in a shared `src/lib/financeDocs.ts` (invoice and receipt share one layout). Pull the client address and email from residents and the payment method and reference from the cashbook entry. The payment details are kept in finance_settings so they can be edited later.
- Receipt number format: R-YYMM###.
